# 📱 Task Manager App (Flutter)

تطبيق إدارة مهام بسيط واحترافي مبني باستخدام Flutter يساعدك على تنظيم يومك وتتبع تقدمك اليومي والشهري والسنوي 📊

---

## ✨ Features

- ✅ إضافة مهام جديدة بسهولة
- 📅 تقسيم المهام (يومي - شهري - سنوي)
- 📊 عرض نسبة الإنجاز بشكل دائري
- 🌙 دعم الوضع الليلي (Dark Mode)
- 🌍 دعم اللغة العربية
- 🔐 تسجيل دخول وإنشاء حساب
- 👤 صفحة إعدادات وملف شخصي
- 📋 قائمة مهام مع إمكانية التحديد (Checkbox)
